写真風の動物がマウスカーソルについてくる、MofuMouseの最初の先行版です。

- 10種・19種類の姿から選べます。
- 1〜10匹を並べ、1匹目・2匹目それぞれに動物と色を指定できます。
- 大きさは32 / 48 / 64 / 96px。マウスの速さに合わせて歩き、止まると待機します。
- 動物はクリックを遮りません。通知領域／メニューバーで一時停止や設定を変更できます。

Windows 10/11の64bit版は `.exe` がインストーラー、`.zip` がフォルダーをそのまま使う版です。ZIPは全体を展開し、`MofuMouse.exe` を起動してください。Apple SiliconのMacは `mac-arm64`、Intel Macは `mac-x64` を選びます。MacはmacOS 13以降に対応するビルドです。

Windowsで基本動作と混在表示を確認しています。Macはビルド・アプリ整合性の確認までで、実機での表示・操作は未確認です。Windowsのコード署名、Apple Developer ID署名・公証は行っていません。

動物の寸法や毛色、歩行の連続性は引き続き調整中です。デグーのブルー／サンドは待機時に静止画になります。モーションのコマ数は種類によって異なります。以前のGo版にあった1px移動やショートカット補助機能は、この先行版には含みません。

ファイル確認用の `SHA256SUMS.txt` を添付しています。
