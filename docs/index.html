MofuMouse

マウスを動かすと、動物たちがあとをついてきます。止まったら、その場でひと休み。

デグー全10色を含む、10種・26種類。好きな組み合わせで1〜10匹を並べられます。

WebでおためしWindows／Mac版を入手

v0.1.0-preview.2 · Windows 10/11 x64 · macOS 12以降

まずは、動かしてみよう。

インストールは不要。Webデモで動物・毛色・大きさを選び、ページ内で追従を試せます。

デモを開く →

クリックを妨げません

動物の下にあるウィンドウも、そのままクリックできます。マウスの速さに合わせて歩きます。

好きな仲間を1〜10匹

1匹ずつ種類と毛色を指定。32・48・64・96pxから大きさを選べます。

いつでもひと休み

通知領域／メニューバーから一時停止・再開。選んだ動物と設定は次回も引き継ぎます。

デグー、全10色がそろいました。

アグーチ、ブルー、サンド、ブラック、ホワイトと、5種類のパイド。デグーの色違いは全30コマの歩行と8コマの待機を収録し、歩行と待機の大きさも合わせました。

基準色アグーチの待機は元の連続動画を保持しています。ほかの動物の歩行コマ数は種類によって異なります。

デモで毛色を選ぶ →

パソコンでも一緒に。

WindowsはインストーラーとZIP。MacはApple Silicon／Intel別のDMGとZIPをご用意しました。macOS 12向け互換版も選べます。
