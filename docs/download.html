はじめかた

  1. アプリを開く。 WindowsはEXEを実行するか、ZIP全体を展開してMofuMouse.exeを起動します。MacはDMGを開き、MofuMouseをアプリケーションフォルダーへ移します。ZIP版も展開したアプリを同じ場所へ移してください。
  2. 動物を選ぶ。 Windowsの通知領域、Macのメニューバーの動物アイコンを開きます。「1匹ずつ選ぶ」で順番ごとに動物と毛色を指定できます。
  3. 数と大きさを調整する。 「表示する数」「大きさ」で変更。「一時停止」で休ませ、「終了」でアプリを閉じられます。

MacのCPUとOSは、Appleメニュー →「このMacについて」で確認できます。WindowsのZIPはexeだけを取り出さず、展開したフォルダー全体を残してください。

Macの初回起動

Mac版はアプリ内部の整合性を確認するためのアドホック署名をしています。Apple Developer ID署名・公証は未実施で、初回に警告が出ることがあります。

公式の配布元とファイルを確認したうえで起動する場合は、一度アプリを開いた後に「システム設定 → プライバシーとセキュリティ」から、このアプリに対する「このまま開く」を選びます。OSによって項目名が異なります。

Apple公式の起動手順をご確認ください。「破損している」「コンピュータに損害を与える」と表示された場合は、起動を進めず再ダウンロードとファイル確認を行ってください。

更新とよくある質問

古い版から更新するには？

動作中のMofuMouseをメニューの「終了」で閉じてから、新しい版を入れてください。Windowsはインストーラーを実行、ZIPは別フォルダーへ全体を展開します。Macはアプリケーション内のMofuMouseを新しい版に置き換えます。preview.1と同じ設定フォルダーを使うため、選んだ動物を引き継ぎます。自動更新はありません。

動物が見えないときは？

通知領域／メニューバーを確認し、一時停止している場合は再開します。表示する数と大きさを確認してください。Windowsの隠れた通知アイコンにもアプリが入っていることがあります。

削除するには？

アプリを終了し、Windowsのインストーラー版は「インストールされているアプリ」から削除します。ZIP版は展開フォルダーを削除。MacはアプリケーションのMofuMouseをゴミ箱へ移します。ユーザー設定は更新のため保持されます。

収録されている動物は？

デグー、チンチラ、ハムスター、モルモット、マカロニマウス、ウサギ、ハリネズミ、フェレット、シマリス、ファンシーマウス。デグーは全10色、全体で26種類です。ほかの動物の追加色は制作中です。

不具合を報告するには？

GitHub Issuesに、アプリの版、OSの版、MacのCPU、選んだ動物、再現手順を記載してください。
