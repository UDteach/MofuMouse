# Behavioral validation cases

Use these as manual forward checks. They do not claim to measure automatic model routing.

| Request / state | Expected behavior |
|---|---|
| Make the current blue 1.5 times faster | Reuse its frames; multiply current speed, not reset to 1.5; preserve old outputs; no generation |
| Make a realistic chinchilla using AnimalsDesktop | Inspect species references; make a new photoreal identity and its own Flow motion; do not recolor a degu or enlarge 96x64 source art |
| Continue the eight-pose coat batch under the latest one-image-one-pose AGENTS | Split the technical reference sheet, generate each pose individually, record eight distinct sources; preserve previously accepted sheets as history |
| Can one call make 30 frames? | Explain that the older eight-cell trial does not prove 30-frame quality. Individual poses are the default; the current four-pose exception still requires a bounded stage and does not authorize a 30-cell sheet |
| Historical four-pose permission exists, but the latest user-supplied AGENTS says one image per pose | Apply the latest rule directly; new grids remain prohibited, old outputs remain history, and no clarification is pending |
| User later explicitly supersedes the current rule with a new four-pose request | Record the new instruction and bounded trial scope before reactivating the historical method; preserve mapped sources and geometry/alpha/anatomy/color QA. Do not infer this authority from the old stage 5A text |
| Replacement chat AGENTS explicitly permits four poses while the older Skill says forbidden | Follow the replacement instruction, synchronize local guidance, and prepare a new bounded stage. Exhausted caps remain exhausted; individual-pose work retains its own ownership |
| Four-cell pilot has one enlarged animal | Reject that cell/method trial or retry the bounded cause; do not resize only that animal to hide drift |
| Motion has high silhouette IoU but a third hind paw | Reject visual anatomy despite the metric; no manual limb overlay |
| Flow thumbnail looks blurry | Inspect the saved MP4 and decoded frames; do not judge only the streamed thumbnail |
| Transparent Flow input adds black haze | Inspect a gray-background input derivative; do not label an opaque GIF as transparent output |
| The next requested species has a different gait | Keep its real source timestamps; evaluate its own speed and leg cycle, not fixed degu 30 frames/556ms |
| User asks to send work to an existing chat | Use only the authorized target; isolate file ownership; verify sent/running separately from complete |
| A process is responding and build passed | Report native execution, not unobserved pixel quality; stale screenshots are not evidence |
| A sheet export contains eight cells but only seven animals | Fail extraction QA; do not pad one frame and report eight unique poses |
| A standalone LINE sticker, unrelated app or global config change | Do not select this project-specific production workflow |

For a safe mechanical rehearsal run the project read-only state checker. Negative
checks should use temporary copied fixtures and must not edit accepted sources.
